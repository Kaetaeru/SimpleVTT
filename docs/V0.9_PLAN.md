# V0.9 — 진행 계획과 상태

**V0.9 정의 (소유자, 2026-09-17):** `CLAUDE.md`의 기준(§1 플레이 가능, §2 하드코딩)을 중심으로 **플레이까지 완벽 통과**.

**압축·새 세션이면:** `CLAUDE.md`를 먼저 다시 읽고, 이 파일의 "상태" 표에서 첫 번째 미완료 슬라이스부터 이어간다.

## 완료 조건

1. `HARDCODE_AUDIT.md` §2의 모든 항목이 JSON으로 옮겨졌거나 §4 예외(이유 기록)로 옮겨졌다.
2. `tests/client/hardcode.test.ts`: `client/`(생성 데이터·`client/data` 제외) 안에서 콘텐츠 ID 리터럴, 특성 키·slug 비교,
   특성 이름·설명문 정규식이 §4 예외 목록 외에 0건이다.
3. SRD가 아닌 **테스트용 모듈**(JSON만)의 직업 특성·주문·몬스터가 SRD와 같은 경로로 자동 처리된다는 호스트 테스트가 있다.
4. **플레이 통과 시나리오** `tests/client/v09-playthrough.test.ts`: 4인 파티(무술·주문·지원·혼합) vs 몬스터 조우를
   이니셔티브부터 전투 종료·짧은 휴식까지 호스트 명령만으로 진행하고, 매 단계에서 계산값이 기대값과 같다.
   수동 입력이 필요한 곳은 전부 상황 버튼·선택 창·"DM 판정" 중 하나로 나타난다.
5. `npm run gate` 통과, exe 빌드는 소유자 요청 시.
