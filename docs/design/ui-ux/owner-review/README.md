# SimpleVTT UI/UX — 내가 직접 정할 것만

이 폴더는 이제 **모든 UI 세부사항을 하나씩 고르는 곳이 아닙니다.**

목표는 간단합니다.

> **SimpleVTT의 사용법을 크게 바꾸는 결정만 제가 고르고, 나머지 세부 UX는 AI가 알아서 일관되게 설계한다.**

---

# 지금까지

`01-foundation-navigation-layout.md`에서 답한 내용은 전부 정식 결정 문서에 반영했습니다.

여기서 이미 정한 것에는 다음이 포함됩니다.

- 기본 메뉴와 화면 이동 방식
- 플레이 화면 우선순위
- 상단 메뉴형 Product Shell
- Actor Board / Initiative / Command Center 큰 배치
- 공식 스타일 시트 + SimpleVTT 시트 선택
- 기존 캐릭터 생성/레벨업 UI 유지
- 부가도구는 옆 패널
- 우클릭 메뉴는 UI/정보 기능만
- 자주 쓰는 행동은 직접 노출
- 사용불가 이유를 호버/포커스로 설명
- 별도 NOTICE UI
- 앱을 완전히 닫았다 켜면 Home에서 시작

따라서 **1번 파일을 더 수정할 필요는 없습니다.**

# 무엇을 더 이상 직접 고르지 않아도 되나요?

다음은 기본적으로 AI가 알아서 정합니다.

- 글씨 크기 단계와 세부 여백
- 버튼 종류와 평범한 Hover/Pressed 상태
- 아이콘 통일 방식
- 일반적인 로딩/빈 화면/오류 표시
- 키보드 포커스의 일반적인 처리
- 좁은 창에서의 평범한 재배치
- 각 패널 안의 세부 간격과 정렬
- 툴팁 문구와 일반 오류문구
- 일반적인 확인창/취소/재시도 문구
- 주사위/VFX의 세부 애니메이션 타이밍
- 컴포넌트를 코드상 몇 개로 나눌지

AI는 이미 정한 제품 방향과 좋은 UX/접근성 원칙 안에서 이런 부분을 설계합니다.

**단, 결과적으로 SimpleVTT 사용법이 크게 달라질 정도의 선택이 생기면 그때만 다시 물어봅니다.**

---

# AI도 마음대로 못 정하는 것

아래는 사용자 취향이 아니라 기술적으로 정확해야 하는 영역이라 AI가 추측하지 않습니다.

- D&D 룰 계산
- 공격/타겟 가능 여부
- 주 손 기본공격이 무엇인지
- DM 비밀정보를 누구에게 전송하는지
- 네트워크 권한
- 세션 재연결 데이터
- 저장/스키마/보안 규칙

이런 것은 별도 Domain/Architecture 계약으로 해결합니다.
