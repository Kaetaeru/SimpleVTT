어렵게 생각하지 않아도 됩니다. 각 질문에서 가장 마음에 드는 보기를 골라 `OWNER SELECT`에 적으면 됩니다.

- `OWNER SELECT` → `A`, `B`, `C`, `CUSTOM`
- `OWNER NOTE` → 추가 의견이 있으면 자유롭게 작성
- `CUSTOM` → 보기 대신 내가 원하는 방식을 직접 작성
