# 여기까지입니다

이 10개 외의 남은 세부 항목은 **사용자가 직접 선택할 필요가 없습니다.**

AI가 다음 원칙으로 처리합니다.

- 이미 Reviewed된 제품 방향을 따른다.
- 자주 쓰는 기능은 쉽게 보이고 조작되게 한다.
- 불필요한 단계와 확인창을 늘리지 않는다.
- 키보드/포커스/오류/로딩/좁은 창 대응은 일반적인 좋은 UX와 접근성 원칙을 적용한다.
- 글씨 크기, 여백, 아이콘, 버튼 종류, 세부 패널 배치는 일관된 디자인 시스템으로 정한다.
- 규칙 계산, 공격 가능 여부, 비밀정보 전달, 네트워크 권한은 UI가 추측하지 않는다.
- 여러 방법이 가능하더라도 **사용자가 체감할 만큼 제품 사용법이 달라지는 경우에만 다시 질문한다.**

원하는 것이 있으면 언제든 자연어로 바꾸라고 말하면 됩니다.
