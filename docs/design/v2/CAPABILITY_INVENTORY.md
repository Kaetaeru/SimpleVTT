## 0. 이 문서의 규칙

**목표 한 줄.** VTT 없이 테이블에서 말로 할 수 있던 모든 것을 앱에서도 할 수 있다. 앱이 "그건 안 됩니다"라고
막는 행동은 없다. 자동화되지 않은 행동은 DM 판정이나 서술로 반드시 흘러간다.

**실행 등급.** 모든 행동은 아래 넷 중 하나로 처리된다. "미지원"은 등급이 아니다.

| 등급 | 뜻 | 사용자가 하는 일 | 앱이 하는 일 |
| --- | --- | --- | --- |
| **A 자동** | 규칙이 결과를 정한다 | 행동 → (대상) 탭 | 굴림·비용·상태 변화·기록·연출 전부 |
| **Q 질문 하나** | 규칙은 있지만 한 사람의 선택이 필요하다 | 예/아니오 또는 목록에서 하나 | 그 답 하나로 나머지를 자동 처리 |
| **R DM 판정** | 규칙이 없거나 DM이 정해야 한다 | 플레이어는 선언, DM은 판정 카드에서 DC·능력·결과·비용 선택 | 굴림·기록·연출, 기본값 제안 |
| **N 서술** | 게임 상태를 바꾸지 않는다 | 선언 입력 | 기록에 남김. DM이 나중에 R로 승격 가능 |

**등급을 정하는 원칙.**
1. 규칙이 결과를 완전히 정하면 A. 사람에게 물을 것이 없다.
2. 규칙이 정하되 선택지가 있으면 Q. 질문은 한 번, 적격자 한 명에게, 두세 개의 선택지로.
3. 규칙이 없으면 R. 앱은 절대 피해 주사위나 DC를 지어내지 않는다. DM 카드에 기본값을 "제안"만 한다.
4. 상태가 바뀌지 않으면 N. 말하기, 몸짓, 분위기 묘사.
5. 어떤 등급이든 되돌릴 수 있고, 사후 수정(토글)이 가능하다.
6. 비용(행동·추가 행동·반응·이동·자원)은 등급과 무관하게 항상 실제로 소비된다. DM 예외(D4)만 이를 면제하며 기록에 남는다.

**표 읽는 법.** `비용` 열은 2024 규칙의 행동 경제. `자유`는 턴당 무료 상호작용 1회 또는 언제나 무료. `입력`은
자동화에 필요한 최소 선택. 사용자에게 거리·좌표를 묻는 입력은 어디에도 없다.

## 1. 소유자가 든 네 가지 예 — 이렇게 처리된다

| 선언 | 규칙 | 등급 | 흐름 |
| --- | --- | --- | --- |
| "전투 중에 갑자기 드러눕는다" | 엎드리기(Drop Prone)는 비용 없음. 일어나기는 이동력 절반 | **A** | 자세 바 `엎드리기` 탭 → 즉시 `넘어짐` 상태. 자신을 향한 근접 공격 유리, 원거리 불리, 자기 공격 불리가 자동 적용. 턴 밖에서도 가능(반응 아님, 자유) |
| "적을 잡아서 던진다" | 붙잡기(Grapple)는 규칙 있음. 던지기는 **규칙 없음** | **A → R** | ① 맨손 타격 → `붙잡기` 선택 → 대상 내성 자동(A). ② `붙잡은 대상 던지기` 선언 → DM 판정 카드(R): 제안 기본값 "근력(운동) 판정 DC 10 + 대상 크기 보정, 성공 시 대상 넘어짐 + 낙하 피해 기준 1d6, 부딪힌 제3자도 같은 피해와 민첩 내성". DM은 승인 카드에서 피해·DC를 그 자리에서 수정하거나 '그냥 성공'을 고른다(D8). 던져진 대상은 교전 해제·넘어짐 |
| "무기를 던진다" | 투척 속성 무기는 원거리 공격으로 규칙 있음. 투척 속성이 없으면 즉흥 무기 1d4, 20/60피트 | **A** | 공격 목록에 투척 가능한 무기는 `던지기` 변형이 함께 뜬다. 던지면 손이 비고 아이템은 장면 바닥으로 이동, `회수 가능` 표시. 투척 속성이 없는 무기/물건은 즉흥 무기로 1d4 자동, 종류(타격/관통/참격)는 DM 토글 |
| "아이템을 버린다" | 물건 놓기는 자유 | **A** | 가방/손에서 `놓기` → 액터에서 장면 바닥으로 이동(삭제 아님). 누구든 `줍기`(자유 상호작용 1회) 가능. DM은 바닥 항목을 지우거나 보관함으로 옮길 수 있다 |

핵심은 두 번째 줄이다. 규칙이 있는 절반은 자동, 없는 절반은 DM 카드로 이어지되 플레이어의 선언은 한 번에 끝난다.

## 2. 세션 밖 — 개인 캐릭터

### 2.1 생성 (D1, D2)
- 안내형/빠른 편집 두 방식, 같은 초안. 종족·배경·클래스를 바꿔도 무관한 입력은 유지.
- 원하는 시작 레벨로 생성. 레벨별 선택을 순서대로 묻되 한 작업으로 완료. 멀티클래스 획득 순서 보존.
- 능력치: 포인트 바이, 표준 배열, 직접 입력(DM 허용). 배경이 주는 능력치 상승·기술·재주.
- 종족 특성, 클래스 특성, 하위 클래스(레벨 3), 주문 선택(알고 있는/준비), 장비 선택 또는 시작 금화.
- 외형·초상화·이름·정렬·성격 메모. 한국어 이름과 검색이 기본, 영문명은 보조.
- 미지원 콘텐츠: "설명만 가능 / 수동 운용 / 자동 실행"을 구분해 표시하고 생성은 막지 않는다.
- 초안 자동 저장, 확정본과 분리, 취소/재시작.

### 2.2 시트 (D1, D3)
- 디지털 탭 시트 / 종이형 시트 선택. 같은 데이터·명령·권한.
- 읽기 전용 파생값: AC, 능력 수정치, 명중 보너스, 주문 DC/명중, 숙련 보너스, 이니셔티브, 이동력, 패시브 지각, 최대 HP.
- 현재 사용량은 인라인 수정: HP(숫자, ±), 임시 HP, 주문 슬롯(칸 클릭), 직업 자원, 히트 다이스, 죽음 내성, 탈진, 영감, 금화, 아이템 수량·충전.
- 원본은 편집 버튼 → 초안 → 바뀌는 수치 비교 → 저장: 기본 능력치, 레벨별 HP 선택, 숙련, 언어, 도구, 출처.
- 임의 결과 오버라이드(예: AC +2 직접 입력)는 없다. 장비·효과의 정상 기여만 반영(D3).
- 상태(조건)를 세션 밖에서도 붙일 수 있다(예: 지난 세션의 저주). 지속 효과 목록.
- 특성·주문·아이템의 설명을 한국어로 읽기. 규칙 원문 링크.
- 계산 확인용 굴림(세션 밖 주사위): 결과는 기록되지만 세션 상태를 바꾸지 않는다.

### 2.3 가방과 장비
- 추가(카탈로그 검색, 사용자 아이템, 메모형), 수량, 충전, 이름/메모, 삭제/복구, 무게 합계(선택 표시).
- 같은 정의의 여러 인스턴스 구분(마법 검 2자루).
- 장착 상태: 갑옷(경/중/중갑, 착용 시간), 방패, 손(주무기/보조/양손/빈손), 반지·망토 등 조율 슬롯.
- 소모품·물약·두루마리·완드·탄약 개수.
- 컨테이너(배낭, 주머니)와 파티 보관함으로 이동.
- "수량 3으로 수정"(관리)과 "물약 마시기"(규칙 행동)의 구분. 세션 밖에서 물약을 마시면 HP가 즉시 오르고 기록됨.

### 2.4 성장
- 레벨업: 필요한 새 선택만 제시, 변경 미리보기, 저장 한 번. 반쪽 레벨업 없음.
- HP 증가: 고정값 또는 굴림. 능력치 상승/재주. 새 주문·교체. 하위 클래스. 멀티클래스 조건.
- 취소/재시작/저장 실패에서 이전 캐릭터 보존.
- 세션 중 레벨업은 DM이 허용한 시점에만(장면 전환·휴식). 그 외에는 예약.

### 2.5 개인 휴식·시간
- 짧은 휴식(히트 다이스 소비), 긴 휴식(HP·슬롯·자원 회복, 탈진 1단계 회복). 세션 밖에서도 실행 가능.
- 회복 규칙은 같은 계산을 쓴다(세션 안 휴식과 동일 함수).

### 2.6 라이브러리와 저장본
- 여러 캐릭터, 복제, 내보내기/가져오기(JSON), 백업 복원, 버전 이관 보고.
- 접속 중 같은 캐릭터의 개인 수정은 live actor를 덮어쓰지 않는다. 재접속 시 revision 충돌 제시.

## 13. 즉흥 행동 프로토콜 — 규칙에 없는 모든 것

플레이어: `즉흥 행동` → 한 줄 선언(자유 텍스트) → (선택) 대상·물건 → 전송. 여기서 플레이어 입력은 끝난다.

DM 판정 카드:
1. **판정 종류**: 능력(근/민/건/지/혜/매) + 기술 제안. 선언 문구로 초기값 추천.
2. **DC**: 10/15/20/25 칩 + 직접 입력. 또는 `대립 판정`(상대 능력 선택).
3. **비용**: 행동/추가 행동/반응/이동/없음. 규칙 위반이면 예외 표시(D4).
4. **결과**: 성공/실패 각각 — 피해(주사위 또는 고정), 상태, 이동/교전 변화, 아이템 이동, 서술.
5. **또는** `그냥 성공` / `그냥 실패` / `서술만` 한 탭.

기본값 제안 표(DM이 언제든 바꾼다):

| 선언 유형 | 제안 판정 | 제안 결과 |
| --- | --- | --- |
| 붙잡은 대상 던지기 | 근력(운동) DC 10 + 크기 보정 | 넘어짐, 낙하 기준 1d6, 부딪힌 자 민첩 내성 |
| 물건 던져 맞히기(피해 목적) | 즉흥 무기 공격 굴림 | 1d4 |
| 물건 던져 넘어뜨리기/방해 | 공격 굴림 또는 대상 민첩 내성 | 넘어짐/불리 |
| 무기 뺏기 | 공격 굴림 vs 대상 근력(운동)/민첩(곡예) | 무기 바닥으로 |
| 밀어서 떨어뜨리기(절벽) | 밀치기 + DM 낙하 높이 | 낙하 피해 |
| 눈 가리기/모래 뿌리기 | 민첩 내성 | 실명 1턴 |
| 샹들리에 타기 등 곡예 | 민첩(곡예) DC 15 | 이동 + 유리 |
| 위협해서 항복 받기 | 매력(위협) vs DC | 태도 변화 |
| 환경 이용(기름 + 불) | 상황별 | 피해 유형별 |

원칙: 앱은 표를 "제안"으로만 보여준다. 승인 카드의 피해·DC·비용은 그 자리에서 수정할 수 있다(D8). DM이 고르기 전에는 아무것도 굴리지 않는다. DM이 고른 뒤에는 A와 똑같이
자동 굴림·연출·기록·되돌리기가 된다. 같은 선언이 반복되면 DM은 "이 판정을 기억"으로 캠페인 규칙에 저장할 수 있다.

## 18. 연출과 피드백

- 주사위: 물리 3D(구현됨). 결과는 상태 확정 뒤 연출. 입력 잠금 0ms.
- 숫자: 피해(유형별 색), 회복, 임시 HP, 상태 칩, 쓰러짐/일어남, 빗나감, 치명타.
- 배너: 해결 하나당 한 줄.
- 이펙트: 투사체/타격/주문/치유. 자유 진행에서도. 강도·음량·모션 축소 설정.
- 결과 카드: 요약 한 줄 + 접힌 상세(주사위·수정치·출처·상태 변화·사후 토글).
- 질문 카드: 적격자 한 명, 비용·대상·`사용/넘김`.
- 거부: 도크 위에 이유 한 줄(한국어), 자동 소멸. 타일 비활성 이유 = 거부 이유.
- 동시 결과: 대상별 순서 유지, 밀린 연출 압축, 재접속 재생 시 이펙트 없음.
- DM 전용 결과는 플레이어 payload에 없다(연출 포함).

## 19. 저장·재접속·비공개·중복

- 명령 ID·권한·기반 revision을 Host가 검사. 같은 명령 재전송은 한 번만 적용.
- durable commit → 수신 확인 순서. 저장 확인 전 "완료" 표시 없음.
- 소유자 write-back: HP·자원·아이템·슬롯·휴식 결과가 순서대로 개인 저장본에. 오프라인이면 대기 후 복구.
- 재접속 커서, 스냅샷 fallback, revision 충돌 시 차이 제시.
- 비공개: 숨은 액터·DM 전용 굴림·귓속말·비공개 자료는 플레이어 wire·기록·VFX 어디에도 없음.
- 두 런타임이 같은 저장본에 동시에 쓰지 않음. 저장본 이관은 복사본에서.

| D9 | 비치명 공격 | **기본안 채택.** 근접 공격으로 0 HP를 만들 때만 죽임/기절 질문, 원거리·주문은 죽임 | §7 |
| D10 | 세션 중 플레이어의 아이템·자원 직접 수정 | **DM 승인.** 플레이어는 정정 요청, DM 승인 시 재량 이벤트로 기록 | §12, §15 |
| D11 | 탈것·물속·비행 | **개편 첫 출시 범위에서 제외.** 그때까지 배지 없음, 선언은 서술 또는 DM 판정으로 처리 | §4, §5 |

답이 없었던 항목은 아래 기본값으로 확정한다. 소유자가 바꾸면 이 표를 갱신한다.

| 항목 | 확정 기본값 |

| 관전자 | 포함하되 보기만 |
