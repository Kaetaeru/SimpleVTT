# V2 · DM Workspace (FVTT / Roll20 형태의 호스트 UI)

Status: **DESIGN — owner mandate (2026-09-07)**

Owner: "FVTT와 Roll20의 호스트와 비슷한 형태의 DM UI를 원했는데 많이 조잡해져버렸었어. 전부 한번에 편하게 등록 가능하고
사용 가능하면 좋겠어. UX를 꼼꼼하게 고려해줘."

Read with `docs/design/v2/TABLE_RUNTIME.md`, `docs/design/ui-ux/CORE-SYSTEMS-UX-PLAN.md` (§9 Quick Search, §11 Command

## 1. 지금 무엇이 조잡한가 (2026-09-07 screenshots, `?session-preview=dm`)

- 상단에 열 개의 도구 버튼(시트·아이템·라이브러리·파티·규칙·Public/DM Only·기록·인카운터·＋빠른 메뉴·세션). 각각이 따로
  오른쪽 패널을 연다. 같은 일이 여러 곳에 흩어져 있다: 액터 등록은 인카운터(SRD 검색)와 라이브러리(캠페인 필요)와 캠페인
  화면(세션 밖)에, 아이템 지급은 아이템 패널과 라이브러리에, HP·상태는 인카운터 → 카드 → "서술 편집" 세 단계 아래에.
- DM 라이브러리는 캠페인이 없으면 비어 있다("세션에 연결된 캠페인이 없습니다"). 준비를 시작할 자리가 없다.
- DM이 플레이어와 같은 하단 도크로 "Aelar"라는 자기 캐릭터를 조작한다. DM에게는 조작할 대상이 선택한 토큰이어야 한다.
- 액터 카드에 DM 조작이 없다. 클릭하면 조작 액터가 바뀔 뿐, HP·상태·시트가 열리지 않는다.
- 플레이어 캐릭터의 시트를 DM이 볼 수 없다. 레벨·자원·장비를 확인할 곳이 없다.

## 2. 구조 — 세 영역, 한 문법

```
┌ 상단 바 ─────────────────────────────────────────────────────────────────────┐
│ ← 캠페인   세션 이름 · 연결 3   [자유 진행 | 이니셔티브]   시계 · 식량   [Public|DM]  Ctrl+K 검색  ⋯ │
├──────────────────────────────────────────────┬────────────────────────────────┤
│ 테이블 (중앙)                                 │ 사이드바 (오른쪽, 항상 열림)      │
│  상대 ─ 토큰 카드들 (무리 접힘)                 │ [기록][전투][액터][아이템][자료][규칙][세션] │
│  ─── 현재 초점: 결과 카드 / 질문 / 핸드아웃 ───  │  검색 ─────────────  [+ 추가]     │
│  아군 ─ 토큰 카드들                            │  목록 (즐겨찾기 · 최근 · 전체)      │
│                                              │  드래그 → 테이블 = 소환/공개/지급    │
├──────────────────────────────────────────────┴────────────────────────────────┤
│ 하단: 선택 토큰의 명령 센터 (핫바)  │  DM 재량 바: HP ± · 상태 · 유리/불리 · 영감 · 되돌리기 │
└──────────────────────────────────────────────────────────────────────────────┘
```

**한 문법.** 사이드바의 모든 탭은 같은 세 줄이다: 검색 · `+ 추가` · 목록. 목록 항목은 같은 동사 버튼을 가진다
(액터 `소환`, 이미지 `보기`/`공개`, 아이템 `지급`/`보관함`, 상태 `적용`, 규칙 `열기`). 드래그해서 테이블에 놓으면 그
항목의 기본 동사가 실행된다. Ctrl+K 검색은 일곱 탭을 한 번에 검색하고 같은 동사를 보여준다 (CORE-SYSTEMS-UX-PLAN §9).

## 3. 사이드바 탭

| 탭 | 내용 | `+ 추가` | 항목 동사 |
| --- | --- | --- | --- |
| 기록 | 굴림·결과·거부·DM 귓속말·시스템. Public/DM Only 필터. 항목 클릭 → 결과 카드 재열람·사후 수정·되돌리기 | 메모 | 공개(DM Only → Public) |
| 전투 | 이니셔티브 순서 (드래그 정렬, 값 직접 편집), 라운드, 현재 턴, 각 줄에 HP·상태 칩·숨김. 이니셔티브 시작/종료·다음 턴·순서 재굴림 | 액터 탭으로 | 턴으로 이동 · 제거 |
| 액터 | ① 파티: 접속 PC (시트 열기 read-only, 레벨·HP·자원·장비) ② 내 NPC: DM 라이브러리 정의 ③ SRD 몬스터 329종 ④ PC 프리셋. 즐겨찾기·최근·폴더·태그 | NPC (SRD에서 복제 → 이름·HP·AC 수정 / JSON / 빈 정의), PC 프리셋(캐릭터 라이브러리에서) | 소환 ×1 · 소환 ×N(무리) · 시트 · 편집 · 복제 · 삭제 |
| 아이템 | DM 커스텀 아이템 + SRD 아이템 + 파티 보관함(GP·아이템) | 커스텀 아이템(카탈로그 복제 / JSON) | 지급(대상 선택) · 보관함으로 · 상세 |
| 자료 | 이미지·노트·핸드아웃 (폴더·태그). 비공개 미리보기 | 이미지(다중 드롭) · 노트 | 보기 · 공개 · 공개 해제 |
| 규칙 | 상태 14종(2024) · 규칙 검색 · 활성 콘텐츠 | — | 적용(선택 토큰) · 열기 |
| 세션 | 접속 주소·참가자·재접속, 시계·식량·휴식, 세션 저장·종료, 표시 옵션(굴림 공개 기본값) | — | — |

**등록은 한 곳.** 액터·아이템·자료의 등록 양식은 세션 안팎에서 같다. 캠페인 화면의 **준비실** 탭은 같은 사이드바를
전체 폭으로 펼친 것이다: 준비실에서 등록한 것이 세션에서 그대로 보이고, 세션에서 등록한 것이 준비실에 남는다.

**라이브러리는 호스트 소유.** DM 라이브러리는 캠페인 없이도 존재한다(호스트 기본 라이브러리). 캠페인은 항목에 태그로
붙는 범위(필터)이지 등록의 전제 조건이 아니다. (DM-LIBRARY-PLAN의 "Campaign-scoped"는 저장 범위였고, 등록 진입을
막는 것이 목적이 아니었다. 비공개·명시적 공개 원칙은 그대로다.)

**한 번에 등록.** 액터 탭 `+ 추가`는 다중 선택을 지원한다: SRD 검색 결과에서 여러 몬스터를 체크해 "내 NPC로 복제",
JSON 한 번에 여러 정의, 이미지 여러 장 드롭. 준비실에는 "장면 묶음"이 있다: 액터 N개 + 이미지 + 노트를 한 묶음으로
저장하고 세션에서 한 번에 소환한다.

## 4. 테이블과 토큰 카드

- 카드 = 초상화 · 이름 · HP 바(수치는 DM에게만, 플레이어에게는 바만 또는 "부상/위독") · AC · 상태 칩 · 턴 표시 ·
  교전 선 · 숨김 표시(DM만) · 무리 접힘(×N, 펼치면 개별).
- **클릭** = 선택(하단 명령 센터와 재량 바가 그 토큰으로 바뀐다). **Shift+클릭** = 다중 선택(재량 바가 전체에 적용).
  **더블클릭** = 시트/스탯 블록. **우클릭 또는 ⋯** = 토큰 HUD.
- **토큰 HUD** (FVTT의 토큰 HUD): HP 입력(−/+ 숫자, 절반, 임시 HP, 최대 HP), 상태 14종 격자(켜기/끄기, 지속 시간
  선택), 유리/불리 다음 굴림, 영웅적 영감, 넘어짐/일어남, 쓰러짐/안정/사망/부활, 교전 대상, 배지(숨음·투명·엄폐),
  숨김, 시트, 제거. 모든 항목이 `TABLE_RUNTIME.md`의 `ruling` 명령이고 기록에 "DM 재량 · …"으로 남는다.
- 드롭 대상: 사이드바 항목을 토큰 위에 놓으면 그 토큰이 대상이다 (아이템 → 지급, 상태 → 적용, 이미지 → 그 토큰
  소유자에게만 공개).

## 5. 하단 — 명령 센터와 재량 바

- 명령 센터는 V1.4의 형태를 유지한다(핫바·경제 칩·이동). DM에게는 **선택 토큰**의 것이다. 토큰이 없으면 비어 있고
  "토큰을 선택하세요"만 보인다. 결과 카드는 중앙 초점에 뜬다.
- 재량 바는 항상 보인다. 왼쪽부터: 피해 입력(숫자·유형·저항 적용 여부) · 회복 · 임시 HP · 상태 팔레트(자주 쓰는 6개 +
  전체) · 유리/불리 · 영감 · 넘어짐 · 되돌리기(Ctrl+Z, 마지막 이벤트 이름 표시). 선택이 없으면 비활성, 다중 선택이면
  "3명에게" 접두사.
- 결과 카드의 사후 수정(치명타 1 → 넘어짐·무기 떨어뜨림·불리점, 피해 정정, 대상 정정)은 카드 안의 "판정" 메뉴다.

## 6. 플레이어 화면

같은 뼈대(UX-02-07). 사이드바 탭은 기록·전투·파티·자료·규칙·세션. 명령 센터는 자기 캐릭터. 재량 바 대신 **자유 행동
바**: 엎드리기/일어서기 · 손 비우기/무기 꺼내기(손 표시: "손: 메이스 · 방패") · 물건 상호작용 · 즉흥 행동 선언(DM에게
DC 질문). 시트는 빠른 시트 + 전체 시트(장착·손·집중 표시).

## 7. 상호작용 규칙

- 확인 대화상자는 되돌릴 수 없는 것에만: 세션 종료, 기록이 있는 액터 삭제, 라이브러리 항목 삭제. 나머지는 되돌리기.
- 모든 목록은 빈 상태에서 `+ 추가`를 크게 보여준다. "없습니다"로 끝나는 빈 화면은 없다.
- 키보드: Ctrl+K 검색, N 다음 턴, Ctrl+Z 되돌리기, Esc 닫기/선택 해제, 1–7 사이드바 탭, Tab 토큰 순환.
- 사이드바 폭 320–420px, 접기 가능(플레이어 기본 접힘). 좁은 창(<1100px)에서는 사이드바가 오버레이.
- 굴림 공개: 상단 토글이 기본값, 기록의 항목별 "공개"가 예외. DM Only 굴림은 플레이어 기록에 "DM이 굴렸습니다"만.
- 접속 플레이어 카드에는 연결 상태 점; 끊긴 플레이어의 캐릭터는 DM이 조작할 수 있다(UX-02-05).

## 8. 프로토타입 장면 (T2-04 evidence)

1. 준비실: SRD에서 고블린·늑대·해골 체크 → 내 NPC로 복제 → "무너진 종탑" 장면 묶음 저장.
2. 세션: 액터 탭에서 묶음 소환 → 전투 탭 이니셔티브 시작 → 토큰 HUD로 고블린 HP −7, 넘어짐 → 재량 바로 두 좀비에 중독
   (1분) → 기록에서 DM Only 굴림 공개 → Ctrl+Z.
3. 자료: 이미지 세 장 드롭 → 하나 보기(비공개) → 한 토큰에 드롭(그 플레이어에게만) → 공개.
4. 플레이어: 손 비우기 → 신성한 불길 시전; 즉흥 행동 선언 → DM DC 15 → 판정.
