## C. 다음 단계에서 추가할 시나리오

- R3 남은 것: 항목 끌어서 정렬, 아바타를 아트 라이브러리에서 고르기(R4), 캐릭터 → 캔버스 끌어 놓기(R5).
- R4 남은 것: 안 쓰는 이미지 정리(GC) 화면, 아트를 캔버스에 끌어 토큰/배경으로(R5).
- R5 남은 것: 육각 격자 그리기, 격자 라벨 표시, 다중 선택 드래그 박스, Ctrl+C/V, 경유점(Waypoints), 시야·빛의 실제 효과(동적 조명).
- R6 남은 것: 행 끌어서 정렬(지금은 ▲▼), 전설 행동 프롬프트, 상태 종료 내성 프롬프트, 시작 시 피해, 지연/준비 행동, 트래커 창 크기 조절.
- R7 남은 것: 무기 숙련(Mastery) 효과, 카드에서 대상 토큰 강조.
- T1 남은 것: 장면 아이콘 끌어서 순서 바꾸기, 장면에 설명 텍스트.
- T4 남은 것: 리본에서 행 클릭으로 카드 강조.
- T3 남은 것: 토스트 길이/개수 설정, 승인 도크의 키보드 조작, 두루마리 시전(SRD 아이템 데이터에 두루마리가 없어 보류), NPC 특성(주문 말고)의 사용 횟수.
- T2 남은 것: 밀어내기 거리(장면에서는 해당 없음), 시트 특성의 추가 행동을 목록으로.
- R8 남은 것: 역공(Counterspell, 시전 가로채기), 두루마리(데이터 없음), 소환·창조물, 카탈로그가 모르는 주문의 자유 기록 카드에 DM 메모, 종료 내성이 "피해를 받을 때"인 주문(지배 계열)은 수동.
- R9 남은 것: 다중공격의 대상을 공격마다 다르게(지금은 한 대상), 루틴의 "대체 가능" 갈래(브레스로 바꾸기)는 DM이 따로 버튼으로, 전설 행동 "공격 한 번"을 카드 안에서 바로 공격으로, 준비한 주문의 슬롯 선소비, 전설 저항(내성 실패를 성공으로) 버튼.
