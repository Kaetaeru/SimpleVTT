# Roll20 테이블 요소 전수 명세 + 반자동 판정 (M4 상세 기획)

- 상태: **기획 (2026-09-15)**. 소유자 지시: "Roll20 세션의 요소를 이니셔티브까지 전부 모조리 구체적으로. 그대로 가져오고, 공격·마법 등 판정만 룰대로 반자동(DM)으로 — 공격 버튼을 누르고 타겟을 선택하면 공격이 되게."
- `ROLL20_MODEL.md`(큰 틀: 캠페인·참가·저널·페이지·채팅)를 요소 단위로 풀어 쓴 것이다. 겹치는 곳은 이 문서가 더 상세하다. 판정 엔진은 옛 V2 커널(`src/table`, `docs/design/v2/RULES_RUNTIME_SPECS.md`, D42)을 이 모델 위로 옮긴다.
- 표기: Roll20 원어 병기. "우리"는 SimpleVTT의 대응. 결정 번호 D81부터.
- 원칙 두 줄: **테이블의 모습·조작은 Roll20 그대로**(그래서 배울 게 없다). **판정은 규칙 엔진이 굴리고 계산하되 DM이 언제든 끼어들어 바꾼다**(반자동, D42).

| Grid | 켜기/끄기, 종류 Square / Hex (H·V), 크기(px, 기본 70), 색, 불투명도, 라벨 표시(A1…) | 정사각·육각 |

| Player View | 플레이어 리본이 이 페이지에 있을 때 플레이어가 봄 | §2.2 |

### 2.2 페이지 도구막대
- 썸네일 줄: 순서 끌어서 바꾸기, 이름, 현재 페이지 강조.
- **플레이어 리본(Player Ribbon)**: 빨간 리본을 썸네일 위로 끌어 놓으면 모든 플레이어가 그 페이지로 이동한다. GM은 리본과 무관하게 아무 페이지나 본다.
- **파티 나누기(Split the Party)**: 리본을 우클릭 → 특정 플레이어만 다른 페이지로 보내는 개인 북마크. 다시 합치기.
- 페이지 추가(+), 복제(Duplicate), 설정(⚙), 보관(Archive, 목록에서 숨김·복구), 삭제.
- D81 우리도 "리본 = 플레이어가 보는 페이지"를 그대로. 리본 이동 시 플레이어 화면이 자동 전환된다.

### 2.3 레이어 (Layers)
| 레이어 | 누가 봄 | 내용 | 조작 |
| --- | --- | --- | --- |
| Map & Background | 모두 | 배경 이미지·지형 그림 | GM만 이동. 플레이어는 클릭도 안 됨 |
| Objects & Tokens | 모두(숨김 토큰 제외) | 토큰·오브젝트·그림 | 자기 토큰(Controlled By)만 이동 |
| GM Info Overlay | GM만 | 메모·함정·비밀문 표시 | GM |
| Dynamic Lighting | GM만(효과는 모두) | 벽·문(일방통행 벽) | GM |

| --- | --- | --- |

| Represents Character | 저널 캐릭터 선택 / 없음 | 같음. 캐릭터가 있으면 시트·속성·권한 상속 |

| Bar 1 / 2 / 3 | value, max, **Link to attribute**(캐릭터 속성 이름), 플레이어에게 보임 / 편집 가능 | HP는 Bar1에 `hp` 연결이 기본(D78) |
| Bar style | 위/아래, 겹침, 숫자 표시 | 같음 |

| GM Notes | GM만 | 같음 |

### 3.2 토큰 설정 창 — 고급 탭
| 필드 | 값 |
| --- | --- |
| Size | 가로·세로(칸), 비율 고정, 회전(°) |
| Vision | Has Sight(시야 켜기), 시야 각도, 시야 거리 제한, 야간 시야(Night Vision, 거리·효과 tint/dim) |
| Light | Emits Light(bright 거리, dim 거리, 각도, 플레이어에게 보임/아니오 = 토큰만) |
| Is Drawing | 토큰이 아닌 그림처럼 취급(스냅·바 없음) |
| Advanced Fog of War | 이 토큰이 안개를 밝힘 |
| Flip H/V | 뒤집기 |

### 3.3 토큰 조작
- **우클릭 라디얼 메뉴**: 바 3개 즉시 편집(`+3`, `-5` 식으로 상대값 입력 가능 — 우리 HP 입력 규약과 동일), 상태 마커 메뉴, 회전 손잡이, "레이어로 이동", "앞으로/뒤로", "기본 토큰으로 저장", "토큰 설정", "복제", "삭제", **"턴 트래커에 추가(Add Turn)"**, "이 토큰으로 말하기".
- **이동**: 드래그(격자 스냅, Alt로 해제), 화살표 키 1칸, 이동 경로(Waypoints: 드래그 중 스페이스로 경유점, 총 거리 표시), 이동 중 자(Ruler) 표시. Roll20은 이동 거리를 제한하지 않는다 — 우리는 §12에서 "이동 속도 초과 시 DM 경고"만(D82).
- **핑(Ping)**: Shift+클릭 → 모두의 화면에 파장, GM은 Shift+클릭으로 플레이어 시야를 그 자리로 끌 수 있음.
- **다중 선택**: 드래그 박스, Shift+클릭. 같이 이동·삭제·레이어 이동.
- **잠금(Lock)**: 지도 레이어로 옮겨 잠그는 관습. 우리는 "잠금" 토글을 하나 둔다(D83).
- **복사/붙여넣기**: Ctrl+C/V, 페이지 간 이동.
- **기본 토큰(Default Token)**: 저널 캐릭터에서 끌어 놓으면 기본 토큰 설정으로 생성. "선택한 토큰을 기본 토큰으로" 저장.
- **연결/비연결 바(D78)**: 바를 속성에 연결하면 같은 캐릭터의 모든 연결 토큰이 값을 공유(PC). 연결하지 않으면 토큰마다 따로(몹). 컴펜디움에서 끌어온 괴물은 기본 **비연결**(HP는 토큰별).

### 3.4 상태 마커 (Status Markers) — 기본 세트와 우리 조건 매핑
Roll20 기본 마커: 빨강·파랑·초록·갈색·보라·분홍·노랑 점, dead(X), skull, sleepy, half-heart, half-haze, interdiction, snail, lightning-helix, spanner, chained-heart, chemical-bolt, death-zone, drink-me, edge-crack, ninja-mask, stopwatch, fishing-net, overdrive, strong, fist, padlock, three-leaves, fluffy-wing, pummeled, tread, arrowed, aura, back-pain, black-flag, bleeding-eye, bolt-shield, broken-heart, cobweb, broken-shield, flying-flag, radioactive, trophy, broken-skull, frozen-orb, rolling-bomb, white-tower, grab, screaming, grenade, sentry-gun, all-for-one, angel-outfit, archery-target 등 (~50).
- D84 우리 마커 세트: 위 세트를 아이콘으로 제공하되, **5e 상태 이상 14종**(장님·매혹·귀머거리·공포·붙잡힘·행동불능·투명·마비·석화·중독·넘어짐·포박·충격·무의식)과 **집중**·**사망**·**은신**·**엄폐 1/2·3/4**는 이름 있는 마커로 고정한다. 시트의 상태(runtime.conditions)와 토큰 마커는 같은 것 — 한쪽을 바꾸면 다른 쪽이 따라온다.
- 숫자 뱃지: 마커 위에 0–9 (탈진 단계, 라운드 남음).

## 4. 저널 (Journal)

### 4.1 공통
- 폴더(중첩), 끌어서 정렬, 이름 검색, 항목마다 아바타.
- 권한 두 필드(D77): **볼 수 있는 사람(In Player's Journals)** / **고칠 수 있는 사람(Can Be Edited By)** = 없음 · 모든 플레이어 · 개별 여러 명. GM은 항상 전부.
- **플레이어에게 보여주기(Show to Players)**: 볼 수 있는 사람의 화면에 창이 자동으로 뜬다(핸드아웃·캐릭터 모두).
- 보관(Archive): 목록에서 숨김, "보관함 보기"로 복구. 삭제는 확인.
- 항목을 캔버스에 끌어 놓기: 캐릭터 → 기본 토큰 생성. 핸드아웃 → (Roll20: 안 됨) 우리도 안 됨.

### 4.2 핸드아웃 창 (Handout)
| 필드 | 내용 |
| --- | --- |
| Name / Avatar | 이름, 대표 이미지(라이브러리·붙여넣기·드롭) |
| Notes | 플레이어 본문. 서식(굵게·기울임·제목·목록·링크·이미지 삽입·표) |
| GM Notes | GM 본문 |
| 권한 두 필드, 보관, 삭제, 플레이어에게 보여주기 | |
- Roll20의 "핸드아웃 링크": 본문에서 다른 저널 항목을 `@` 또는 끌어 놓기로 링크. 우리도 지원(D85).

### 4.3 캐릭터 창 (Character) — 탭 셋
| 탭 | 내용 | 우리 |
| --- | --- | --- |
| **Bio & Info** | Avatar, Name, In Player's Journals, Can Be Edited By(=Controlled By), Bio(본문), GM Notes, **Default Token**(현재 저장된 기본 토큰 미리보기, "선택 토큰으로 갱신"), Tags, Archive, Duplicate, Delete, Export to Vault | 같음. Export는 캠페인 설정이 허용할 때 플레이어도 |
| **Character Sheet** | 시스템 시트. 굴림 버튼 → 채팅 롤 템플릿 | 우리 시트(생성·운용·효과·주사위). **공격·주문·특성 버튼이 §12 반자동 판정으로 이어진다** |
| **Attributes & Abilities** | 속성 목록(name/current/max, 토큰 바 연결 대상), 능력(매크로 본문, "토큰 액션으로 표시", "매크로 바에 표시") | 속성은 파생값 자동(HP·AC·이니셔티브 보너스·이동·지각·내성·기술). 능력 = 매크로(§8) |
| NPC 시트 | 컴펜디움 괴물 스탯 블록: 능력치·AC·HP·이동·감각·언어·CR·특성·행동(Multiattack, 무기 공격, 브레스…)·전설 행동·재충전. 행동마다 굴림 버튼 | V2 커널의 스탯 블록·재충전·전설 행동을 이식. **행동 버튼도 §12 반자동** |

### 4.4 Vault ↔ 캠페인 (D73)
- 테이블 저널의 "+ 캐릭터": (a) **새로 만들기**(생성 마법사가 저널 창 안에서 열림, 설정이 허용하면 플레이어도) (b) **내 라이브러리에서 가져오기**(목록에서 선택 → 사본이 캠페인에 생김, Controlled By = 가져온 사람).
- 캐릭터 창 → **라이브러리로 내보내기**(사본을 라이브러리에 저장, 같은 id면 덮어쓰기 확인). 설정 `playersCanExportToVault`.
- 캠페인의 사본이 원본. 라이브러리 것은 건드리지 않는다.

| `d20r<2` | 재굴림 조건 | 추가 |
| `d6!` | 폭발 | 추가 |
| `d20cs>19 cf<2` | 치명·실패 범위 | 추가 |
| `1t[표이름]` | 굴림표 | §8 |
| `{2d6, 1d8}kh1` | 그룹 | 나중 |
| `+ @{속성}` | 속성 참조 | §8 |
- D86 파서를 확장한다: 기존 `parseFormula`에 kh/kl/d/r/!/cs/cf를 더하고, 결과 카드에 버려진 눈은 취소선.

### 5.3 롤 템플릿 (카드)
- 시트 굴림 카드: 이름·라벨(공격/피해/판정/내성)·식·눈·수정치·합·강조(20/1). 공격 카드는 명중과 피해가 한 카드.
- **판정 카드(§12)**: 공격자→대상, 명중 굴림 vs AC, 적중/빗나감, 피해(속성·저항 반영), 적용 결과(HP 변화), DM 팔레트 버튼(GM만 보임).
- 카드 접기/펼치기, 이전 카드 클릭으로 "다시 굴리기"(GM).

## 6. 턴 트래커 (Turn Tracker)

### 6.1 창
- GM이 열면 모든 플레이어에게도 뜬다(GM이 닫으면 사라짐). 끌어서 옮김, 크기 조절.
- 항목: 토큰 아바타·이름·**이니셔티브 값(편집 가능)**, 현재 턴 강조(캔버스의 토큰에도 테두리). 순서 끌어서 바꾸기.
- 버튼: ▶ **다음 턴(Advance Turn)**, 정렬 ▲▼(값 순), 항목 추가(+ Custom: 이름·값 — "라운드" 카운터를 이렇게 쓴다: 값에 `+1` 식이면 턴이 돌 때마다 증가), 전체 비우기, 항목 삭제.
- 토큰이 없는 항목(커스텀)도 순서에 낀다.

### 6.2 넣는 방법
- 토큰 우클릭 → "턴 추가(Add Turn)": 이니셔티브 0으로 들어감. 시트/컴펜디움에서 "이니셔티브 굴림"을 누르면 **굴림 결과가 값으로 들어간다**(같은 토큰이 있으면 갱신).
- 여러 토큰 선택 후 굴림 → 한꺼번에.

### 6.3 우리 확장 (D76, D87)
- 라운드 카운터는 기본 항목("라운드 N")으로 항상 있고, 턴이 한 바퀴 돌면 +1. 시계도 6초 전진(V2 §1).
- **다음 턴**을 누르면: 지금 턴이 끝나는 액터의 "턴 끝" 처리(효과 라운드 진행, 지속 피해, 상태 종료 내성 프롬프트) → 다음 액터의 "턴 시작" 처리(재충전 굴림, 시작 시 피해, 0 HP PC의 죽음 내성 프롬프트) → 트래커·토큰 강조 이동 → 채팅에 "○○의 턴".
- 전설 행동: 다른 액터의 턴 끝마다 사용 가능 프롬프트(GM). 지연 행동/준비 행동(V2 `ready`): 항목 순서 조정.
- 이니셔티브 시작: GM "전투 시작" → 선택 토큰·페이지의 모든 토큰 중 고른 것을 트래커에 넣고 각자 굴림(PC는 플레이어에게 "굴리세요" 요청 또는 자동, 설정).

## 10. 안개와 조명 (Fog of War · Dynamic Lighting)

- **기본 안개**: 페이지 설정에서 켬. GM이 도구로 사각/다각형을 밝히거나 되덮음. 플레이어는 밝혀진 곳만(반투명 검정). "GM은 밝은 안개로 봄".
- **고급 안개(Advanced Fog)**: 토큰 시야로 밝혀진 곳을 "탐험됨"으로 기억(어둡게 남음).

- 우리: 기본 안개 R9, 동적 조명은 V2 커널 이식 후(시야 규칙이 판정과 얽힘 — 어둠·엄폐는 D42대로 DM 팔레트로 넣고 자동 판정은 하지 않는다).

## 12. 반자동 판정 (여기부터가 Roll20에 없는 부분)

원칙(D42 계승): **규칙 엔진이 굴리고 계산해서 카드로 보여 주고, DM이 확정한다.** 기본 설정은 "자동 적용(플레이어 간·PC↔NPC 모두 즉시 반영, DM은 사후 수정)"이며, 캠페인 설정으로 "DM 확인 후 적용"으로 바꿀 수 있다(D90). 어느 쪽이든 DM 팔레트는 항상 있다.

### 12.1 대상 지정 (Targeting)
- 시작점 셋: (a) 시트의 **공격 행 "공격" 버튼**, (b) 토큰 선택 시 위에 뜨는 **토큰 액션 줄**(공격·주문·특성), (c) NPC 시트의 **행동 버튼**.
- 누르면 커서가 과녁 모양이 되고 안내 바가 뜬다: "대상을 클릭하세요 (Esc 취소, 여러 대상은 Shift)". 후보 토큰에 테두리, 사거리 밖 토큰은 흐리게(사거리 = 자 도구와 같은 격자 거리).
- 클릭 → 대상 확정 → 판정 시작. 주문의 범위 템플릿은 §12.4.
- Roll20의 `@{target|…}` 매크로 타겟팅과 같은 사용감(대상 클릭)으로 맞춘다.
- 대상이 없는 것(자신 대상 주문·특성 사용·회복)은 바로 실행.

### 12.2 공격 흐름 (무기 공격·주문 공격)
1. **명중 굴림**: 1d20 + 시트의 명중 보너스(출처 표시). 유리/불리: 공격자·대상의 상태(넘어짐·투명·마비·행동불능·포박·충격·무의식·장님, 엄폐 마커, 은신)에서 규칙대로 자동 제안하고 DM 팔레트로 바꿀 수 있음. 2d20 굴림은 두 눈을 모두 카드에.
2. **AC 비교**: 대상의 AC(PC 시트 / NPC 스탯 블록 / 토큰 속성). 20은 자동 적중·치명타, 1은 자동 실패. 카드에 "적중(17 vs AC 15)".
3. **피해 굴림**: 무기·주문 피해 주사위 + 보너스, 치명타면 주사위 2배. **라이더 프롬프트**: 암습(조건 충족 시 자동 제안), 신성한 강타(슬롯 선택), 격노 보너스(효과에서 자동), 통달 속성(V2 이식), 추가 피해 주문(사냥꾼의 표식·헥스 자동).
4. **적용**: 대상의 저항·면역·취약(스탯 블록/시트 방어)으로 조정 → 임시 HP → HP. 카드에 "피해 11 참격 (저항 → 5)". 대상이 PC면 그 시트에, NPC면 토큰 바(비연결) 또는 NPC 시트(연결).
5. **후속 프롬프트**: 대상이 집중 중이면 **집중 내성**(DC = max(10, 피해/2)) 자동 굴림 카드(PC는 "플레이어가 굴리기" 옵션); 0 HP → PC는 무의식 마커 + 죽음 내성 시작, NPC는 사망 마커(즉사 규칙: 남는 피해 ≥ 최대 HP면 PC도 즉사 경고); 넘어짐·붙잡힘 등 무기 통달 효과 적용.
6. **채팅 카드**: 공격자→대상, 굴림 전부, 결과, 적용 요약. GM에게만 팔레트 버튼: 강제 적중/빗나감/치명타, 엄폐 +2/+5, 유리/불리 재굴림, 피해 수정(±N, 절반, 0), **되돌리기(undo)**, 메모. 팔레트 조작은 카드에 "DM 수정: …"으로 남는다.
- 반응: 대상이 **방패(Shield)** 주문을 준비했다면 "반응: 방패? (+5 AC)" 프롬프트가 대상 플레이어에게 먼저 간다(V2 반응 창 §2). 기회 공격은 이동 규칙(§12.6).

### 12.3 내성 판정을 요구하는 주문·효과
1. 시전 버튼(시트, 이미 있음) → 대상 지정(단일/범위) → 슬롯 소비(이미 있음).
2. 대상마다 **내성 굴림**: NPC는 자동(스탯 블록 내성), PC는 설정에 따라 자동 또는 "플레이어에게 요청" 카드(버튼 하나로 굴림, 30초 뒤 DM이 대신 굴릴 수 있음).
3. 성공/실패 → 피해(성공 시 절반 등 주문 데이터의 규칙) 또는 상태 부여(실패 시 마커 + 시트 상태 + 지속 시간 효과). 상태 종료 내성은 트래커 "턴 끝"에 자동 프롬프트.
4. 카드에 대상별 줄: 이름·굴림·DC·결과·적용.
- 회복 주문: 대상 지정 → 회복량 굴림 → 적용(최대 HP 제한, 죽음 내성 초기화).
- 소환·환경 주문: 규칙 없음 → 카드에 텍스트 + DM 메모(V2 "규칙 없음" 등급).

### 12.4 범위 (AoE)
- 시전 시 주문 데이터의 범위(원뿔 15ft, 반지름 20ft, 선 60ft…)를 자 템플릿으로 자동 선택 → GM/플레이어가 캔버스에 놓음 → 템플릿 안 토큰이 대상 목록(체크박스로 빼기) → 확정.
- 템플릿은 카드에 남고 "모두에게 보이기".

### 12.5 이니셔티브·턴과의 연결
- "전투 시작" → 참가 토큰 선택 → 각자 이니셔티브(PC: 시트 보너스 + 특성; NPC: 스탯 블록) → 트래커 정렬.
- 턴 시작/끝 처리(§6.3). 자기 턴이 아닌 액터의 행동 버튼은 "반응/자유 행동"만 활성(설정으로 해제 가능 — Roll20은 제한이 없으므로 기본은 **경고만**, D91).
- 행동 경제 표시(행동·추가 행동·반응·이동 남음)는 토큰 액션 줄 옆에 작은 칩으로; 초과 시 경고, 막지 않음(D91).

### 12.6 이동과 기회 공격
- 토큰 이동 시 이동 속도 초과면 경로가 빨갛게(경고). 적의 사정거리에서 벗어나는 이동이면 그 적의 조종자에게 "기회 공격?" 반응 프롬프트(V2 `declare/withdraw`, 이탈 행동이면 없음).

### 12.6b 행동 목록 (2024) — R9
- 액션 줄에 **행동** 묶음: 그래플·밀치기(대상 지정 → 대상의 근력/민첩 내성 DC 8+근력 수정치+숙련 → 실패 시 붙잡힘/넘어짐 또는 5ft 밀림), 탈출(붙잡힌 쪽의 근력/민첩 판정 vs DC), 회피(효과: 다음 턴 시작까지 자신을 노리는 공격은 불리, 민첩 내성 유리), 질주(이동 두 배 — 이동 경고 기준), 이탈(이 턴 이동은 기회 공격을 유발하지 않음), 도움(대상의 다음 판정/공격에 유리 효과), 은신(은신 판정 → 결과가 DC; 지각·수색과 비교, 은신 마커), 수색(지각/조사 판정), 준비(발동 조건 텍스트 + 준비된 행동, 트리거 시 반응 소비), 설득(매력 판정 vs DC), 활용·마법·학습(판정 또는 시전으로 연결).
- 모두 카드로 남고 DM 팔레트로 고칠 수 있다. 조건이 붙는 효과(회피·도움·준비)는 시트의 진행 중인 효과로 들어가 트래커의 턴 처리로 끝난다.

### 12.7 특성·자원
- 시트의 "사용"(이미 있음)은 그대로. 대상이 필요한 특성(안수 타인, 바드의 영감 주기, 신성 변환 대상)은 대상 지정으로 이어진다.
- 휴식: GM이 "휴식 제안"(V2 D30) → 각 플레이어가 히트 다이스 선택 → 완료. 시계 전진.

### 12.8 상태와 죽음
- 상태 = 토큰 마커 = 시트 상태(D84). 판정이 부여하고, 트래커가 종료 내성을 묻고, DM이 마커를 직접 켜고 끈다.
- PC 0 HP: 무의식·넘어짐 마커, 턴 시작마다 죽음 내성 카드(플레이어 굴림), 3 성공 안정 / 3 실패 사망(마커). 회복하면 초기화. NPC 0 HP: 사망 마커, 트래커에서 흐리게.

- **D95 장면 우선 (Theatre of the Mind)**: 격자 지도는 R5–R7까지 만든 상태로 두고, 기본 방식은 위치가 없는 "장면"이다. 장면에서는 앱이 거리·사거리·엄폐·유리를 판단하지 않는다 — 규칙 추적(HP·상태·집중·반응·죽음 내성)은 그대로 하되, 상황 판단은 DM이 반자동으로 넣는다: 판정 전 대화(유리·불리, 엄폐 +2/+5, 반드시 적중/치명타/빗나감)와 판정 후 팔레트. 플레이어는 유리/불리만 선언할 수 있다. 캠페인 설정 "테이블 방식"으로 격자로 바꿀 수 있고, 장면 캠페인에서도 "+ 격자 페이지"를 쓸 수 있다.
- **D96 벗어남 = 기회 공격 유발**: 위치가 없으므로 기회 공격은 이동하는 쪽이 선언한다. 자기 턴(또는 자기 토큰을 선택한 상태)에 상대 아이콘의 "🏃 벗어남"을 누르면 그 상대의 조종자(NPC면 DM)에게 프롬프트 카드가 가고, 근접 공격 하나를 반응으로 쓰거나 "안 함"을 고른다. 반응은 트래커 행에 기록되어 다음 자기 턴 시작까지 한 번뿐이다. 회피(Disengage) 행동이 이를 막는 것은 R9(행동 목록)에서.
- **D97 턴 패널 = 공식 행동 목록**: 트래커의 현재 턴이 자기 것이면(플레이어는 자기 캐릭터, DM은 어느 플레이어도 조종하지 않는 인물) 보드 위에 2024 행동 목록이 뜬다. 앱은 행동을 판정하고(내성·기술 판정, 주사위 전부 표시) 상태를 표시하되, 행동 경제(행동·추가 행동·반응)는 보여 주기만 하고 막지 않는다 — 추가 공격·특성은 DM과 플레이어가 안다. 위치가 없으므로 이동·거리 항목은 없고, 질주는 기록만 남긴다.
- **D98 특성·아이템도 턴 패널에서**: 직업·종족·특기의 사용 가능한 특성과 가방의 물건을 자기 턴 패널 메뉴에서 바로 쓴다. 시트와 같은 활성화 규칙(자원 소비, 회복/임시 HP 주사위, 효과 시작)을 공용 모듈로 쓰고, 물약은 등급별 회복 주사위, 소모품은 수량이 줄고, 나머지는 기록만 남긴다. 판정 메뉴는 내성 6·기술 18을 굴린다.
- **D99 UI는 세 종류**: 기록(채팅 카드, 영구), 알림(토스트, 일방적 통지, 몇 초 뒤 사라짐), 승인(도크·모달, 어느 한쪽의 답을 기다림). 화면에 늘 떠 있는 것은 승인뿐이며, 나머지는 채팅으로 돌아가 보면 된다. 장면은 절대 스크롤 프레임이 아니다.
- **D100 상황별 초점 하나**: 화면은 그 순간 가장 중요한 것 하나를 크게, 나머지를 작게 보여 준다. 전투 전엔 무대, 남의 턴엔 행동 중인 카드와 리본, 내 턴엔 커맨드 바, 대상 지정엔 후보 카드, 답을 기다릴 땐 오버레이, 결과는 그 일이 벌어진 카드 위에. 같은 정보를 두 곳에 동시에 크게 두지 않는다(채팅은 기록, 보드는 지금). 크기·색(금 = 내 차례, 빨강 = 공격/피해, 초록 = 성공)·어둡게 하기·위치(위 = 순서, 아래 = 내 행동, 가운데 = 답해야 할 것)로 구분한다.
- **D101 턴 순서 바는 발더스 게이트 3 식**: 지금 차례를 맨 앞에 크게 금테로, 이어지는 차례를 작은 초상으로 왼쪽→오른쪽. 적은 붉은 테, 일행은 푸른 테, 초상 아래 HP 바, 임시 HP 고리, 연속한 일행 묶음(같은 이니셔티브 그룹)에 화살표·모래시계, 쓰러지면 회색. 라운드 숫자는 왼쪽 끝에 작게.
- **D102 주문도 반자동, 실행 카탈로그대로**: 주문은 `spellExecutionCatalog`(SRD 5.2 주문 실행 정의)가 아는 만큼만 굴린다 — 주문 공격(명중·피해, 소마법 레벨 스케일), 내성 피해(성공 시 없음/절반, 범위는 한 번 굴려 모두에게), 복합 피해, 내성 효과(상태·지속), 회복(수정치 포함, 최대 HP 이내), 임시 HP, 자동 명중 투사체(마법 화살), 여러 번 주문 공격, 추적 효과(축복·집중). 그 밖의 주문은 "기록" 카드(무슨 일이 있었는지 DM이 말로). 대상은 장면 아이콘 클릭(최대 인원은 카탈로그의 maxTargets), 슬롯/횟수는 시트의 `castOptions`대로 대화로 고르고 호스트가 소비·집중 시작. NPC는 스탯 블록의 주문 목록(의지대로·n/일; DC = 블록의 DC, 명중 = DC−8)으로 시전하되 횟수는 아직 세지 않는다. 판정 전 조정(유리·엄폐·반드시)은 주문 공격에도 같은 대화. 되돌리기·D90 확인 대기는 공격과 같은 길.
- **D103 NPC의 내성 행동은 주문처럼**: 브레스·시선·전설의 휩쓸기 같은 스탯 블록의 "내성 굴림" 행동은 `npcSaveExec`가 주문 실행 정의로 바꿔(내성 능력·DC·실패 피해 주사위·성공 시 절반/없음·실패 상태) 주문 해결기로 굴린다. 대상은 아이콘 여러 개 클릭(범위 안은 DM이 고른다, D95), 카드는 주문 카드와 같고 "NPC 행동" 표시, 재충전(5–6 등)은 쓰는 순간 소비되어 그 인물의 턴 시작에 굴러 돌아온다(되돌리면 복구). 다중공격은 스탯 블록의 루틴(찢기×3)을 버튼 하나로: 대상 하나, DM 판정 전 조정 대화 한 번, 공격마다 카드 하나.

- D81 리본 = 플레이어 페이지. D82 이동 초과는 경고만. D83 토큰 잠금 토글. D84 마커 세트 + 5e 상태 고정, 마커 = 시트 상태. D85 저널 링크. D86 굴림 문법 확장(kh/kl/d/r/!/cs/cf). D87 트래커 다음 턴이 턴 시작/끝 처리. D88 시트 버튼이 곧 토큰 액션. D89 자 템플릿 → 대상 후보. D90 기본 자동 적용 + DM 팔레트, 설정으로 "DM 확인 후 적용". D91 행동 경제·턴 밖 행동은 경고만.
- D92 PC의 내성 굴림은 기본 **자동**(NPC와 같이 호스트가 굴려 카드로). 플레이어가 자기 설정에서 "직접 굴리기"로 바꿀 수 있는 옵션은 이후 단계.
- D93 판정 카드는 주사위 눈을 **전부** 보여 준다(GM 굴림·귓속말 굴림만 예외).
