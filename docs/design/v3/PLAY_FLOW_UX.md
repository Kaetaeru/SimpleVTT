# 플레이 흐름 개편 — 직관적이고 편안한 플레이

작성: 2026-09-17 · 브랜치 `claude/practical-newton-rye61w` · 출발점 `bb4f4f92`

소유자 지시(2026-09-17): 세션 화면과 캐릭터 시트의 UI를 다시 배치하고, 재주·특성의 종류와 발동 방식에 맞는
플레이 흐름을 설계한 뒤, 슬라이스를 나눠 끝까지 진행한다. 최종 목표는 **직관적이고 편안한 플레이**.

같은 대화에서 정해진 것:
- 명중을 조건으로 하는 선택(대형 무기 달인의 중량 무기 숙달 등)은 **명중한 뒤** 반응 창처럼 승인받는다.
- 암습·신성한 강타·야만적 공격자도 같은 창으로 옮긴다.
- 대상의 반응(방패 등)을 먼저 묻고, 그래도 명중이면 공격자에게 묻는다.
- 특성마다 "매번 묻기 / 항상 사용 / 안 씀"을 고를 수 있게 한다(별도 슬라이스).

## 1. 지금 화면에서 본 것 (증거: `docs/evidence/new-client-m1`, 2026-09-17 재촬영)

### 테이블 (63, 64, 67, 68)
1. **무대의 가운데가 비어 있다.** 장면 카드가 화면 대부분을 차지하는데 배경 그림이 없으면 빈 상자다. NPC 카드와
   플레이어 카드는 왼쪽 끝에 작게 붙어 있다.
2. **턴 트래커가 무대를 덮는다.** 떠 있는 창이라 장면 한가운데를 가리고, 위쪽 턴 리본과 내용이 겹친다.
3. **알림 토스트와 3D 주사위가 무대 위에 겹친다.** 토스트 세 줄이 플레이어 카드 옆을 가린다.
4. **턴 패널이 메뉴 더미다.** 공격 버튼 줄 아래에 행동▾ 추가 행동▾ 판정▾ 반응▾ 특성▾ 아이템▾가 나란히 있다.
   무엇을 할 수 있는지 **열어 봐야** 안다. 쓸 수 있는 특성(행동 폭증 1/1, 재기의 바람 2/2)이 메뉴 안에 숨는다.
5. **특성이 발동 방식과 무관하게 한 메뉴에 섞인다.** 추가 행동 특성만 "추가 행동" 메뉴로 가고, 나머지(행동, 자유,
   반응 아닌 것)는 전부 "특성"에 있다. 구분 근거는 활성화 메모의 글자("추가 행동")뿐이다.
6. **공격 전 대화가 굴리기 전에 선택을 강요한다.** 암습·강타·야만적 공격자·계약 라이더를 명중 여부도 모르고
   체크해야 한다. 2024 규칙은 대부분 "명중했을 때" 결정한다.
7. **헤더가 붐빈다.** 캠페인 이름, 연결 상태, 참가자, 참가 코드, 게임 시각, +10분, +1시간, 짧은/긴 휴식, 트래커,
   설정, 닫기가 한 줄에 있다.

### 캐릭터 시트 (24, 38)
8. **정체성이 아래에 있다.** 시트를 열면 HP 입력·휴식·주사위 도구·진행 중 효과·상태 칩·기록이 먼저 나오고,
   이름·직업·AC·능력치는 그 아래다.
9. **상태 18개가 늘 칩으로 깔려 있다.** 걸린 상태와 안 걸린 상태가 같은 무게로 보인다.
10. **HP 입력이 암호 같다.** `12 · -4 · +4 · ++4` 한 칸에 네 가지 의미.
11. **공격·특성·주문이 발동 방식이 아니라 출처(직업/종족/재주)로 묶인다.** 플레이 중에는 "지금 무엇을 쓸 수
    있나"가 필요하다.

## 2. 원칙

- **보이는 것이 할 수 있는 것이다.** 쓸 수 있는 행동은 버튼으로 보이고, 못 쓰면 흐려지며 이유가 붙는다.
- **선택은 결정에 필요한 정보가 생긴 순간에 묻는다.** 명중 전에 명중 후의 일을 묻지 않는다.
- **묻는 횟수는 플레이어가 줄인다.** 매번 묻기·항상·안 씀.
- **무대는 인물의 자리다.** 떠 있는 창·토스트·주사위는 인물을 가리지 않는 가장자리에 둔다.
- **플레이 중 시트는 "쓰는 곳", 만들기·레벨업 시트는 "읽는 곳"이다.** 순서가 다르다.
- 기존 원칙 유지: 판정은 호스트, 규칙은 카탈로그(계약), 없는 것을 있는 척하지 않는다(D168), 위치 없음(D109).

## 3. 발동 방식 분류 — 무엇이 어디에 나타나는가

| 분류 | 예 | 나타나는 곳 | 근거 |
|---|---|---|---|
| 상시 | 중갑 달인의 피해 감소, 격노 중 저항 | 시트 줄, 계산에 자동 반영 | `property.modify` |
| 사용 · 행동 | 제2의 바람(2014식), 행동 폭증(자유) | 턴 패널의 **행동 줄** 버튼 | 계약 `payments` 경제 버킷 / 활성화 메모 |
| 사용 · 추가 행동 | 재기의 바람, 교활한 행동 | 턴 패널의 **추가 행동 줄** 버튼 | 〃 |
| 사용 · 반응 | 오싹한 회피 | 반응 줄 + 해당 순간의 프롬프트 | 〃 |
| 판정 전 선언 | 쪼개기, 보조 손, 무모한 공격 | 공격 전 대화 (필요할 때만 뜸) | `pre-roll-attack` |
| **명중 후 선택** | 대형 무기 달인, 암습, 신성한 강타, 야만적 공격자, 돌격자, 관통자 | **명중 후 승인 창** (신규) | `on-hit` (신규) |
| 굴림 뒤 구조 | 불굴, 행운 | 실패 카드의 구조 버튼 | `d20.roll` 인터셉터 (R35) |
| 피격 반응 | 방패, 공격 흘리기, 가로막기 | 피격 프롬프트 | `reaction.window` (R54) |
| 결과 뒤 자동 | 베어 넘기기의 추가 행동, 강화된 치명타 마크 | 로그 + 턴 경제 | `attack.resolved` (R53) |
| 표 판단 | 탈것, 부엌 | 시트의 "표에서 판단" 줄 | `adjudication.request` |

## 4. 공격 한 번의 흐름 (목표)

1. 턴 패널에서 무기 버튼 → 과녁 모드에서 대상 클릭.
2. **판정 전 대화는 선언할 것이 있을 때만** 뜬다(쪼개기·보조 손·DM의 엄폐/강제 결과). 없으면 바로 굴린다.
3. 호스트가 굴린다. 빗나가면 카드로 끝.
4. 대상에게 반응이 있으면 대상에게 묻는다(방패 등). 빗나감이 되면 끝.
5. 공격자에게 **명중 후 선택**이 있으면 묻는다. 치명타 여부와 굴린 주사위가 보인 상태에서 고른다.
   "항상 사용"으로 둔 것은 묻지 않고 적용, "안 씀"은 제외.
6. 같은 주사위로 다시 계산해 적용한다. 비용(슬롯·자원)은 이때 낸다.
7. 결과 뒤 자동 효과(R53)가 로그와 턴 경제에 반영된다.

## 5. 슬라이스

각 슬라이스는 코드 + 단위 시험 + (화면이 바뀌면) E2E + 결정 기록 D번호 + 로드맵 행 + 커밋·푸시.
`gate:client` → `gate:e2e` 순서로, 동시에 돌리지 않는다.

| 슬라이스 | 내용 | 끝났다고 말할 조건 |
|---|---|---|
| **R63 명중 후 승인 창** | `on-hit` 진입점, 호스트 보류(대상 반응 다음), 프로토콜 v30 프롬프트·답 명령, 계약 4개(대형 무기 달인·돌격자·관통자·선술집 싸움꾼)와 하드코딩 3개(암습·강타·야만적 공격자) 이동, 대형 무기 달인의 "턴당 한 번" 제거 | 명중 시 창이 뜨고, 고르면 같은 주사위로 피해가 늘고, 치명타면 추가 주사위도 두 배, 비용 지불, 안 함이면 그대로 |
| **R64 특성별 사용 설정** | 런타임에 특성별 정책(ask/always/never), 시트에서 전환, 호스트가 always는 묻지 않고 적용 | 항상 사용이 창 없이 적용되고 설정이 저장·동기화됨 |
| **R65 턴 패널 재배치** | 메뉴 더미를 발동 방식별 줄(공격 / 행동 / 추가 행동 / 반응)로, 쓸 수 있는 특성은 버튼으로 남은 횟수와 함께, 판정·아이템은 한 곳에 | 열지 않고도 이번 턴에 쓸 수 있는 것이 보임 |
| **R66 무대 배치** | 트래커를 무대 위 떠 있는 창에서 가장자리 도크로, 토스트·주사위를 인물 밖으로, NPC·플레이어 줄이 너비를 쓰고 장면 카드는 필요한 만큼만 | 무대의 인물 카드가 어떤 창에도 가려지지 않음 |
| **R67 플레이 시트 재배치** | 이름·직업·AC·HP가 맨 위, 걸린 상태만 표시(추가는 버튼), HP 입력을 피해·회복·임시 버튼으로, 특성을 발동 방식별로 | 시트 첫 화면에서 정체성과 전투 수치가 보임 |
| **R68 헤더 정리** | 시간·휴식 도구를 DM 메뉴로 접고, 참가 코드는 복사 버튼 하나로 | 헤더 한 줄이 넘치지 않음 |

순서의 이유: R63·R64는 흐름의 뼈대라 R65(턴 패널)가 그 위에 선다. 화면 배치(R65~R68)는 서로 독립이라 하나가
막혀도 다음으로 넘어간다.

## 6. 소유자에게 올릴 것 (작업 중 쌓임)

- 치명타 피해가 일반 피해로 보인 건: 판정기·호스트 단위로는 재현되지 않음(대검 12→20, 대형 도끼 11→18).
