# 잿빛 관문의 늑대들 — 시어터 오브 마인드 원샷 (2024 규칙)

1레벨 2인 파티(클레릭 세라, 파이터 카엘)와 DM. 지도 없이 서술과 선언으로만 진행하는 한 세션(약 2시간)
분량. 이 문서는 시나리오 자체와, 각 비트를 SimpleVTT의 어떤 조작으로 굴리는지의 대응표, 그리고 실제
윈도우 세 창(DM 호스트 + 플레이어 둘)으로 굴린 결과를 함께 적는다. 러너:
`scripts/run-tauri-e2e-tom-scenario.mjs` (런처 `-TOM`, 워크플로 `Theater-of-Mind Scenario Windows Verification`).

## 배경

잿빛 관문은 마을 북쪽 숲 끝에 선 옛 감시탑의 무너진 문이다. 보름 전부터 밤마다 늑대 울음이 관문 쪽에서
내려오고, 사흘 전 양치기 하나가 돌아오지 않았다. 촌장 브람은 마을에 머물던 두 모험가에게 관문을 살펴
달라고 청한다. 관문 안에서는 고블린 보스 "이빨"이 해골 둘을 부리며 늑대 무리를 사냥개처럼 풀어 두고 있다.

## 장면

### 장면 1 · 쉬어가는 등불 여관 (자유 진행)

- 촌장 브람이 의뢰를 꺼낸다. 선금은 없다. 세라가 마을을 위해 나서 달라고 설득한다.
- **판정**: 세라, 매력(설득) 판정. DC 12. 성공하면 브람이 건량 엿새치를 내준다(캠페인 식량 +6).
- DM은 캠페인 달력에 메모를 남긴다: "1일차 해질녘 · 쉬어가는 등불 여관".

### 장면 2 · 숲길 매복 (이니셔티브)

- 해가 진 숲길. **장면 조건: 어둠**. 늑대 세 마리가 무리로 덤불에 숨어 있다(배지 숨음).
- **판정**: 카엘, 지혜(지각) 탐색. 성공하면 매복을 눈치채고 늑대들이 드러난다(배지 해제).
- **이니셔티브 시작**. 늑대는 한 무리로 우선권을 한 번만 굴린다.
- 늑대 1이 카엘을 문다(+4, 2d4+2 관통). 명중 여부와 상관없이 늑대 1과 카엘은 **교전** 상태가 된다.
- 카엘이 늑대 2를 대검으로 벤다. 세라가 늑대 3에게 신성한 불길(민첩 내성 DC 13, 1d8 광휘)을 건다.
- 다음 라운드, 카엘이 **물러남**을 선언한다. 카엘 자신의 대검 공격으로 늑대 2와 교전 중이고(늑대 1과의 교전은
  한 라운드 동안 근접 공격이 없어 끝났다) 늑대 2의 반응이 남아 있으므로 DM에게 **기회공격 프롬프트**가
  뜬다. DM은 늑대 2의 기회공격을 고른다.
- 남은 늑대들은 울부짖으며 어둠 속으로 흩어진다. **이니셔티브 종료**, 늑대 제거, 어둠 해제.

### 막간 · 야영 (장기 휴식)

- 파티는 숲가에 불을 피운다. DM이 두 플레이어에게 **장기 휴식을 제안**한다: 캠페인 시간 +8시간, 하루치
  식량 소비 포함. 각 플레이어가 자기 창에서 **승인**한다.
- 결과: HP·주문 슬롯 회복, 달력 8시간 진행, 식량 잔량 감소.

### 장면 3 · 잿빛 관문 (이니셔티브)

- 무너진 문 앞. 해골 둘이 문을 지키고, 고블린 보스 이빨이 탑 안에서 나온다.
- **판정**: 세라가 문턱의 함정을 찾는 지능(조사) 연구 판정. DC 15.
- **이니셔티브 시작**. 이빨이 탑 그늘에서 단궁을 쏜다. DM은 **명중 굴림을 숨긴다**(플레이어에게는 공격과
  결과만 보이고 d20은 안 보임). 뒤에 DM이 굴림을 **공개**한다.
- 다음 라운드, 보스의 턴에 DM이 **다중공격**(시미터 2회)을 카엘에게 한 번에 굴린다.
- 세라가 치유의 단어(추가 행동, 1d4+3)로 카엘을 치료한다. 카엘이 해골 1을 벤다. 세라가 유도 화살을
  보스에게 쏜다.
- **이니셔티브 종료**. DM이 두 캐릭터에게 XP 150을 지급한다.

### 마무리

- DM이 **세션 종료**. 플레이어는 오프라인으로 돌아가고, 캠페인에는 세션 요약(참가자, 달력 전/후, 식량
  변화)이 남는다.

**플레이하면서 잡아 고친 결함** (모두 PR #381):

1. 근접 판정으로 생긴 교전이 DM이 카드를 닫기 전까지 플레이어에게 전파되지 않았다 → 판정 이벤트가 교전을 싣는다.
2. 완료된 결과 카드가 열려 있으면 플레이어 이동 선언이 "보류"되고, DM이 고른 기회공격이 조용히 거부되며, DM 도구의 이니셔티브 버튼이 잠겼다 → 진행 중(스테이지) 판정만 막는다.
3. 장기 휴식 뒤 캠페인 시계·식량이 플레이어 화면에 반영되지 않았다 → 커밋 뒤 투영을 방송한다.
4. 전투에서 다친 플레이어(라이브러리 런타임 리비전이 오른 캐릭터)에게 장기 휴식 제안이 조용히 거부됐다 → 플레이어가 기록을 저장하면 호스트 투영 리비전을 갱신한다; 거부는 화면에 표시된다.
5. 먼저 승인한 플레이어의 휴식이 확정되면 뒤 플레이어의 승인이 "캠페인 리비전 오래됨"으로 거부됐다 → 호스트가 제안을 현재 리비전으로 재도장하고, 플레이어는 앞선 리비전을 받아들인다.
6. 내성에 성공한 주문 결과가 "operation skipped by predicate"로 보였다 → "늑대 3 내성 성공 · 피해 없음".
7. 공개 항목 제목이 판정 ID였고, 전투가 끝나도 물러남 칩이 남았다 → 행동 이름으로 표기, 이니셔티브 종료 시 선언 소거.

**남은 것 (설계 판단 필요)**:

- 파티 장기 휴식을 플레이어마다 따로 제안하면 "캠페인 시간 +8h · 하루치 식량"이 제안마다 적용된다(둘 다 승인하면 16시간·식량 4). 파티 단위 휴식(시간·식량은 한 번)이 맞다. 지금은 DM이 두 번째 제안부터 두 옵션을 끄는 것으로 우회.
- 자유 진행에서는 이동 선언 행(접근/물러남/그대로)이 도크에 없다. 시어터 오브 마인드의 서술 장면에서도 선언을 쓰고 싶다면 자유 진행에도 노출할 것.
