# 무너진 종탑 — 시어터 오브 마인드 원샷 2 (2024 규칙)

1레벨 2인 파티(클레릭 세라, 파이터 카엘)와 DM. 첫 시나리오(잿빛 관문의 늑대들)가 "한 판이 굴러가는가"를 봤다면,
이 시나리오는 **모든 플레이 종류**와 **일부러 틀린 플레이**를 한 세션 안에 넣는다: 아이템 지급과 사용, 집중 주문과
집중 판정, 붙잡기(내성 굴림), 준비 행동과 반응, DM의 HP·상태 조정, 쓰러짐·죽음 내성·안정화·치유로 일어남, 되돌리기,
슬롯 소진 거부, 행동 소진 거부, 남의 턴 거부. 러너: `scripts/run-tauri-e2e-tom2-scenario.mjs` (런처 `-TOM2`,
워크플로 `Fallen Bell Tower Scenario Windows Verification`). V1.6 S1-04.

## 배경

마을 동쪽 언덕의 옛 종탑이 지난 겨울 무너졌다. 무너진 계단 아래에서 밤마다 종이 울린다. 종을 치는 것은 종탑에
묻힌 종지기의 뼈들 — 좀비 둘과 해골 하나 — 이고, 종루에는 이 소리에 이끌려 온 홉고블린 전사가 자리를 잡았다.

## 장면

### 장면 1 · 종탑 아래 마을 (자유 진행)

- 약초상 노파가 카엘에게 **치유 물약** 하나를 건넨다(DM 라이브러리 → 카엘 인벤토리, 모든 창에서 수량 1).
- 세라가 카엘에게 **신앙의 방패**(1레벨, 집중)를 건다. 카엘의 AC가 +2 되어 모든 창에 같은 값으로 보인다.
- 카엘이 세라를 **도움**(행동, 판정 없음)한다.
- **틀린 플레이**: 세라가 적 대상 주문(신성한 불길)을 자기 자신에게 → "그 대상에게는 사용할 수 없습니다." 거부.

### 장면 2 · 무너진 계단 (이니셔티브)

- 좀비 둘과 해골 하나가 계단에서 올라온다. DM이 좀비 1에게 **넘어짐** 상태를 건다(모든 창에 칩).
- **틀린 플레이**: 세라가 신성한 불길을 좀비 둘에게 → "대상은 최대 1명입니다." 거부.
- **이니셔티브 시작**. 카엘의 턴: 해골을 **붙잡기**(맨손 타격 · 붙잡기, 해골의 근력 내성). 해골이 실패하면
  **붙잡힘** 칩이 붙는다. 이어 카엘이 대검을 휘두르려 하면 → "행동을 이미 사용했습니다." 거부. 카엘은 **회피**
  대신 남은 이동을 그대로 두고 턴을 넘긴다.
- 세라의 턴: 세라가 **인도**(집중)를 카엘에게 건다 — 신앙의 방패 집중이 끝나 카엘의 AC가 원래대로 돌아간다
  (모든 창). **틀린 플레이**: 세라가 같은 턴에 **상처 치료**(행동)를 또 쓰려 한다 → 거부.
- 좀비 1의 턴: DM이 세라를 후려친다. 명중하면 세라에게 **집중 판정**이 세라 창에만 뜬다. 세라가 d20을 굴려(3)
  실패 → 인도가 끝난다.
- 카엘의 턴: 카엘이 **준비 행동**을 건다 — "해골이 다가오면 대검". 해골의 턴에 카엘이 **반응**으로 준비한 공격을
  쏜다(호스트가 굴려 모두에게 연출, 준비 설정은 정확히 한 번 해제).
- DM이 카엘에게 **HP 절반**과 **-5**를 서술 피해로 적용한다(모든 창). 이어 좀비 2가 카엘을 쓰러뜨린다(HP 0).
- 카엘의 턴: 무기 타일은 전부 "의식불명 · 죽음 내성 굴림만" 잠긴다. 카엘이 **죽음 내성 굴림**(12 → 성공).
- 세라의 턴: **안정화**(지혜(의학) 판정 DC 10) → 카엘 안정. 다음 턴 **상처 치료**로 카엘이 일어난다(HP > 0,
  모든 창). 카엘이 **치유 물약**을 마신다(수량 0, HP 회복).
- **이니셔티브 종료**.

### 막간 · 되돌리기

- DM이 마지막 판정을 **되돌린다**. 보상 이벤트가 모든 창에 도착하고 원래 기록은 남는다.

### 장면 3 · 종루 (이니셔티브)

- 홉고블린 전사가 종루에서 내려온다. **이니셔티브 시작**.
- 세라의 턴: 1레벨 슬롯이 다 떨어졌다(신앙의 방패, 상처 치료). **틀린 플레이**: 유도 화살 → 슬롯 부족 거부.
  세라는 대신 신성한 불길을 건다.
- **틀린 플레이**: 카엘이 세라의 턴에 투창을 던진다 → "현재 Actor의 턴이 아닙니다." 거부. 카엘의 턴에 던지면 확정.
- **이니셔티브 종료**. DM이 XP 100을 지급하고 세션을 종료한다.

## VTT 대응표

| 비트 | 조작 | 검증 |
| --- | --- | --- |
| 물약 지급 | DM 라이브러리 `upsertCampaignDmLibraryEntry` + `grantCampaignDmLibraryItem` | 세 창의 카엘 인벤토리 수량 1 |
| 신앙의 방패 | P1 `resolveAction` (spellId shield-of-faith) → 호스트 확정 | 세 창의 카엘 AC +2 |
| 도움 | P2 `action.standard.help` → 세라 | 활동 기록 수렴 |
| 대상 초과 | P1 신성한 불길 대상 둘 | P1 도크 거부 + DM 거부 알림 |
| 넘어짐 | 호스트 `setCreatureStatus(좀비1,"넘어짐",true)` | 세 창의 상태 칩 |
| 붙잡기 | P2 `action.unarmed-strike.grapple` → 해골 (해골 내성 d20 3) | 해골에 붙잡힘 칩, 세 창 |
| 행동 소진 | P2 대검 같은 턴 | 거부 "행동을 이미 사용했습니다." |
| 인도로 집중 교체 | P1 인도 → 카엘 | 카엘 AC 원래대로, 호스트 집중 = 인도 |
| 집중 판정 | 좀비 1 → 세라 명중(d20 19), P1 `submitConcentrationSaveD20(3)` | P2에는 프롬프트 없음, 실패 후 집중 없음 |
| 준비 행동 | P2 `configureReadyAction`, 해골 턴에 trigger 액션 | 호스트 설정 보유 → 발사 후 해제 |
| 서술 피해 | 호스트 `applyNarrativeDamage(카엘,"half")`, `(-5)` | 세 창 HP |
| 쓰러짐 | 호스트 `applyNarrativeDamage(카엘,999)` | 카엘 타일 잠김 사유 "의식불명" |
| 죽음 내성 | P2 `action.death-save` (d20 12) | 성공 1/3 세 창 |
| 안정화 | P1 `action.standard.stabilize` → 카엘 (d20 15) | 카엘 안정 |
| 일어남 | P1 상처 치료 → 카엘 | HP > 0 세 창 |
| 물약 | P2 `action.healing-potion` | 수량 0, HP 상승 |
| 되돌리기 | 호스트 `undoLastResolution` | 보상 이벤트 세 창, 원 기록 유지 |
| 슬롯 소진 | P1 유도 화살 | 거부(한국어 사유) |
| 남의 턴 | P2 투창 세라 턴 | 거부 "현재 Actor의 턴이 아닙니다." |
| XP·종료 | `grantCampaignAdvancement`, 세션 종료 | 세션 요약 1건 |
