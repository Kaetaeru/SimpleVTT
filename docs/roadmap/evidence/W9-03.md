## Journey (`scripts/run-tauri-e2e-w9-03.mjs`, `-W903`, real Tauri DM Host + player peer)

1. **J1 first run** — both peers start on fresh data roots and complete the first-run choices.
2. **Importer** — both peers import and activate the golden external module (`homebrew.golden-v1`) through the real Contents screen: the player to build the Character, the Host to resolve the projected content identities and the feature's Common Play definition.
3. **J2 Character** — the player creates a Character with the imported Background (떠돌이 길잡이) and levels it through production level-ups to Fighter 3, choosing the imported Subclass (주문검사) in the subclass acquisition choice; the imported feature (비전 일격) is granted by stable ID.
4. **J3/J4 Session 1** — the Host creates a Campaign and opens a direct network Session; the player joins with the golden Character; the DM walks the real Initiative to that Character's turn and resolves the imported feature through the authoritative Host path; the player's Activity records it.
5. **J5/J6 restart** — both processes are killed and relaunched on the same data roots; the module activation survives on the Host, and the Character, its imported Subclass id, and its grant survive on the player.
6. **J7–J9 Session 2** — the Host reopens the Session, the player rejoins with the same Character, and the imported feature resolves again and reaches the peer.

Screenshots and body text for every stage, plus `w9-03-summary.json`, are in the WIN artifact.
