## What was built (PR #324, iterated on the integration branch)

- `scripts/run-tauri-e2e-w8-02.mjs` extends the existing Tauri/WebDriver runner to launch a DM Host and three player instances on isolated data roots: P1 and P2 join and the Host settles two ordered authoritative results (`orchestration`); P3 joins late and replays only the missing ordered history once, landing on the Host cursor without a reroll while every peer's Scene converges with the Host (`p3-late-join`); a third result after the join reaches P1, P2, and P3 in the same Activity order (`post-join-order`).
- `.github/workflows/w8-02-tauri.yml` runs it on `windows-latest` with `-W802` and uploads the per-instance screenshots, body text, runtime snapshots, and the summary JSON.
- The `-W802` switch lives in the shared dispatcher `scripts/run-tauri-e2e.ps1` alongside the other gates; no second E2E framework.
